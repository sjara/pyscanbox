# User Guide — pyscanbox

Welcome to the **pyscanbox** User Guide! This software package is designed to control a [Neurolabware](https://neurolabware.com/) two-photon microscope. It provides a Python-based alternative to the original MATLAB-based [Scanbox](https://www.scanbox.org/) software.

This guide will walk you through installing the software, understanding its user interface, and providing a step-by-step tutorial on how to run a typical imaging session.

Note that you can run **pyscanbox** in emulation mode even if you don't have the microscope hardware.
