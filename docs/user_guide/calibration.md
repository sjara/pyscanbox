# Hardware Calibration

Calibration tools are accessible from **Calibration** drop-down menu situated along the top menu bar.
For each feature or device a dedicated dialog will overlay the application.

## Calibrate Bidir Scan
Instructions for calibrating the bidirectional scanning and saving the calibration for future session. This process ensures that lines captured during negative scanning resonances overlap consistently over lines captured during positive scanning passes.
Calibration values are saved as an NPZ file in the folder of the config.yaml file used.
The auto-calibration mode is still under development.

## Calibrate ETL
Instructions for calibrating the relation between voltage and focal plane for the Electrically Tunable Lens (ETL). 

## Calibrate Pockels Cell
Instructions for calibrating the relation between laser power and Pockels cell voltage. This calibration requires a light power meter.

## Calibrate Scanner Gains
Instructions for setting a different resonant scanner gain, which changes the aspect ratio of the pixels. The resonant scanner gain is set as a multiplier with respect to the Galvo gain defined in the config file.
